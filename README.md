### WRFv4.5.1 for WFIP3 Model Development  ###

This repository is a frozen snapshot of the WRF model code used during the Third Wind Forecast Improvement Project (WFIP3). This code was run in realtime to support the Event Log and weather discussions of WFIP3 (Bodini et al. 2026), while the code was developed to improved offshore wind and cloud forecasts in the WFIP3 region. This code is archived to support NOAA-led publications and should not be referenced prior to reaching out to the main developers (Joseph Olson and Xia Sun, NOAA/GSL).


Many modifications have been made to the original v4.5.1 code. The main modifications include: (1) major update to the MYNN-EDMF, (2) addition of a HRRR diagnostics module, and (3) the implementation of the old (HRRRv4) version of the MYNN-EDMF bouandary layer scheme for a better apples-to-apples comparison of model physics updates.
